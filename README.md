# Geospatial Training Portfolio

A growing collection of practical, beginner-friendly GIS and remote-sensing exercises using QGIS, open geospatial data, and Python.

The aim of this portfolio is to demonstrate two things: the ability to work through geospatial tasks carefully, and the ability to explain each workflow clearly to a learner.

## Portfolio projects

| Project | What it demonstrates | Status |
|---|---|---|
| [01 — DEM terrain analysis in QGIS](projects/01-dem-terrain-qgis/README.md) | Raster basics, coordinate reference systems, terrain derivatives, map layout, and clear practical instructions | Tutorial outline in progress |
| 02 — Python raster inspector | Reading raster metadata and checking spatial properties with Python | Planned |

## How to use this portfolio

Each practical is intended to include:
- the learning objectives and prerequisites;
- the data source and licence/attribution notes;
- numbered steps that a learner can reproduce;
- expected outputs and quality checks;
- common errors and troubleshooting notes.

## About the work

These are independent learning and teaching demonstrations built with public or synthetic data. They are not thesis chapters, unpublished research results, or a reproduction of a confidential research workflow. A project will be marked as complete only after its workflow has been run and checked.

## Tools

- QGIS
- Python (planned for the raster-inspection exercise)
- Publicly available geospatial datasets

## Current status

This portfolio is under development. Screenshots, outputs, and completion claims will be added only after the practicals have been personally carried out and verified.
